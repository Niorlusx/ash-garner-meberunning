Static Ash Garner / Ash G / Meberunning landing page for 3630 VIC. Dark Melbourne trap aesthetic, streaming links, membership tiers, waitlist, and OG metadata.

## Preview

Run `python3 -m http.server 8080` from this directory. No build step or npm is required.

- `index.html` — landing markup, catalog, pricing, FAQ, waitlist
- `css/styles.css` — responsive crimson and blue theme
- `js/config.js` — Stripe Payment Link placeholders
- `js/main.js` — waitlist behavior
- `og-image.png` — social share image
- `stripe-setup.md` — Stripe setup notes
